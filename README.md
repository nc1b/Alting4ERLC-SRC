# Alting4ERLC-SRC

## Repository status

This repository currently contains a compiled `main.pyc` artifact and does not include the original Python source or a documented build process.

Because compiled bytecode is difficult to audit, treat it as an untrusted release artifact:

- Do not run it on a machine that contains Roblox, Discord, or other sensitive credentials unless you have independently verified the file.
- Do not disable antivirus or SmartScreen warnings to run it.
- Keep credentials out of command-line arguments and source files.
- Prefer a source-available release with reproducible build instructions.

## Reporting a concern

If you discover suspicious behavior, preserve the file hash and report the issue privately to the repository owner. Do not publish tokens, cookies, or other secrets in an issue.
